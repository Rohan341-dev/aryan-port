# Aryan Mahato — Portfolio

A modern, dark-themed personal portfolio for Aryan Mahato (Grade 9 student & beginner developer).
Built with only **HTML5, CSS3 and vanilla JavaScript** — no frameworks, no backend.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Structure

```
aryan-portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── images/   ← replace gallery placeholders here
    └── icons/
```

## Customize

- **Gallery images** — swap the `src` in the Creative Corner section with `assets/images/...`
- **Email / socials** — update the links in the Contact section of `index.html`
- **Colors** — edit the CSS variables at the top of `style.css`
- **Projects** — edit the project cards inside the Projects section
